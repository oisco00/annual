아래 프로그램은 GitHub Desktop + Netlify로 운영 중인 '통합 연차관리'입니다.
현재 버전은 v7.2이고 GitHub 저장소는 Thesaga_Annual, Netlify 주소는 https://thesaga-annual.netlify.app 입니다.
기존 Netlify Blobs 운영자료가 절대로 초기화되지 않도록 호환성을 유지하여 수정해 주세요.

현재 핵심 기준:
- 시스템 전용계정은 통합관리자와 대표이사 2개만 사용
- 직원은 실제 직원 계정이며 통합관리자가 '연차 승인자' 체크 가능
- 다단계 순차승인 후 대표이사 최종승인
- 퇴사일 및 재직/퇴사일등록자/전체 조회
- 통합관리자만 직원 삭제 가능
- 신규직원/PW초기화 기본 비밀번호 1111
- 기존 직원 40명, 연차기록 761건/808.5일 자료 구조 유지
- 기존 반차, 공휴일, 연차주기, Excel, 백업 기능 유지

수정 후에는 ZIP 전체파일과 비전문가용 업데이트 설명서를 함께 제공해 주세요.
